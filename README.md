# Reporte de Implementación de Chat con Socket.io 🦋

## Descripción
Se implementó un chat simple utilizando **Node.js**, **Express** y **Socket.io** 🦋.

- El servidor corre en `http://localhost:3000` 🦋.
- El chat funciona así: los usuarios se conectan y los mensajes se transmiten en tiempo real 🦋.

## Conclusiones 🦋

Aunque hubo varios errores al principio, todo se solucionó. El chat básico con WebSockets está funcionando correctamente y listo para ser probado 🦋.

## Función adicional sorpresa 🦋:
Digno de un virus informático de los 🦋2000’s🦋, la función especial que hice crea una **explosión de emojis** cada vez que se envían mensajes, los cuales aumentan en cantidad con cada mensaje subsecuente 🦋. 🦋🦋
